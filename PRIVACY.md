# Privacy Policy

`AemiRegex` is an open-source Linear-time RE2 and RFC 9485 regular-expression engine for Swift, licensed under the MIT License.

## Data Collection and Telemetry

- **No telemetry or analytics:** `AemiRegex` collects, stores, and transmits **zero** telemetry, usage analytics, crash reports, or personal data.
- **No network access:** `AemiRegex` performs no outbound network requests and contains no tracking, licensing, or phone-home logic.

## Data Processed Locally

As a compiled Swift library, `AemiRegex` processes only the in-memory inputs and local filesystem paths provided directly by the host application or tool that links it.

## GDPR and Enterprise Compliance

`AemiRegex` operates strictly within the calling process and transmits no data to external services.
