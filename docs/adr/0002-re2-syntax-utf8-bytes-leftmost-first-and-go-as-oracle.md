# 0002 — RE2 syntax, UTF-8 bytes, leftmost-first, and Go as the oracle

## Context

A syntax, a text model and a match rule had to be chosen before anything else, and each needs an independent answer to check against.

## Decision

- **Syntax:** RE2's (as Go and Rust implement it), minus what is not built yet.
- **Text:** UTF-8 bytes. Classes and `.` match whole scalars; bytes that are not valid UTF-8 match nothing; a match never starts inside a
  valid scalar. `\d \w \s \b` are ASCII, as in RE2 and Go. `(?i)` folds ASCII only until roadmap 0005.
- **Rule:** leftmost-first (Perl, RE2, Go), not leftmost-longest. POSIX needs another mode.
- **Iteration:** an empty match that touches the previous match is skipped, and the position advances one scalar. Probed against Go:
  `a*` on `baaac` gives `[0,0] [1,4] [5,5]`, and `x*` on `héx` gives no match inside `é`.
- **Oracle:** Go's `regexp`. Expected values are generated by Go (`Scripts/golden/`) and checked in; a CI job regenerates them and diffs.

## Evidence and divergences

103 curated patterns x 23 haystacks and 2,000 generated patterns x 4 haystacks agree with Go. **Deliberate differences**, probed: Go 1.27
accepts a duplicate group name and a name starting with a digit (RE2 and Rust reject both); AemiRegex rejects both, because a name that
maps to two groups is ambiguous. ICU is **not** an oracle for assertions: it differs from RE2 on `\b`, `\B`, `$` and multiline `^` in
some cases, and on three generated cases Go sided with AemiRegex. `DifferentialTests` therefore generates no assertions.

## Consequences

Unicode classes and case folding are roadmap 0005. Other dialects are front ends over this machinery with their own oracles (ADR-0006).
