# Diary — 2026-10-25 (01)

## Project set up like ask; I-Regexp built (roadmap 0004)

The project got a white paper, ADR-0001 to ADR-0007, the roadmap (0001 to 0014, in the owner's order: I-Regexp, Unicode, then the Rust
gap), `AGENTS.md` and this diary, with `DocumentationLayoutTests` enforcing the layout. Each of the four rules was broken on purpose and
fired. Then roadmap 0004. ADR-0008 holds the one decision made on the way.

## Probe ledger

| Claim | Probe | Verdict |
|---|---|---|
| I remember RFC 9485's grammar | fetched the RFC (486 lines) and read Figure 1 | **Partly wrong**: `[^]` is explicitly forbidden; `Cs` is not an allowed category; `{n,m}` has no ordering rule in the grammar; `^` and `$` are ordinary characters; `-` and `,` are listed as normal characters |
| I-Regexp is a search | RFC section 4 and 5.3 / 5.4 | **REFUTED**: the result is Boolean over a whole string; the RFC maps to `\A(?:` ... `)\z` |
| The RFC's RE2 mapping is complete | read section 5.4 against the grammar | **REFUTED**: it replaces `.` but does not escape `^` and `$`, which the grammar makes ordinary and RE2 reads as anchors. AemiRegex escapes them. Whether an erratum exists: not checked |
| Go can be the oracle for matching | run the RFC's mapping through Go on 198 patterns x 32 haystacks | Holds for everything except `C`, `Cn` and `Cs`: Go has no unassigned category, and its `C` excludes unassigned code points. Those are unit-tested on U+0378 |
| A recogniser written from the ABNF can be the oracle for the grammar | independent Go recogniser (iterative), 8,000 generated patterns, 3,433 valid | AemiRegex agrees on every one, after the test's own length-limit mistake below |
| The standard library can supply general categories | scanned all 1,114,112 scalars, built the sets | Holds. First use **46.6 ms**, warm 0.56 ms, `\p{L}` is 4,508 instructions; ADR-0008 |
| A reversed class range is caught by the translator | `\n[z-a]` (the translation moves the offset) | Holds after a test that can tell the two apart; `[z-a]` alone could not (the offsets coincide) |

## Mutations

Baseline proved green first (80 tests). Six mutations, each restored from a copy: an unescaped `]` accepted as a normal character; `.` not
narrowed to `[^\n\r]`; `^` and `$` not escaped; the reversed-range check removed from the translator; `C` without unassigned code points;
the whole-string anchors dropped. All turned the suite red (1 to 7 issues). Four documentation rules were broken the same way: a blocker
that does not exist, an unknown ADR status, an unfinished entry blocked by a finished one, a diary file over its budget.

## Mistakes

- **My own test hit the wrong limit.** A 200,000-byte nesting pattern correctly tripped the 64 KB length limit first; the test raised it
  to reach the depth limit and now asserts both.
- **Scripted edits missed after the formatter rewrapped signatures, again** (three times: `Pattern.init`, `Parser.compile`, `makePlan`).
  The build caught each. AGENTS.md already says to grep after a scripted edit; the habit is still not reliable, so the build, not the
  script's "ok", is what counts.
- **A roadmap blocker went stale** the moment 0004 finished (0005 and 0013 waited on it). `DocumentationLayoutTests` caught it.

## Unicode: scripts, aliases, folding (roadmap 0005, ADR-0009)

### Probe ledger

| Claim | Probe | Verdict |
|---|---|---|
| The standard library's categories match Go's | all 1,114,112 scalars, both Unicode 17.0.0 | Holds: 0 mismatches |
| The standard library can supply case folding | orbits derived from lower and upper mappings (38.8 ms) against Go's 1,482 | **REFUTED**: 5 orbits differ. `ı` is merged into {I, i}; {U+0390, U+1FD3}, {U+03B0, U+1FE3} and {U+FB05, U+FB06} are missing (simple-folding entries no case mapping gives) |
| The standard library has scripts | read `Unicode.Scalar.Properties` | **REFUTED**: none |
| Go's `\p` is RE2's | ran 18 spellings through Go 1.27 | **REFUTED**: names are matched loosely (`gr_eek`, `GREEK`, ` Greek`), and `Any`, `Assigned`, `Ascii`, `Lc`, 42 long-name aliases (`Letter`, `punct`) and `Cn` exist; `Latn`, `Script=Greek`, `\pg` are errors |
| Go's `C` excludes unassigned code points, and has no `Cn` | counted: `C` 954,481 = `Cc Cf Co Cs` 139,751 + `Cn` 814,730 | **REFUTED for Go 1.27** (true of older Go). My ADR-0008 and the I-Regexp tests said so; both stale. The two readings of `C` coincide, so the `xsd` switch was removed |
| A generated table beats the stdlib scan | cold `\p{L}` | 0.85 ms against 46.6 ms |
| The generator's output needs no formatting | formatted it and compared | **No at first**: `swift-format` adds digit-group underscores (7 or more digits) and drops a trailing blank line. The generator now emits what the formatter emits; `cmp` is exact |

### Mutations

Baseline proved green first (92 tests). Six, each restored from a copy and each turning the suite red: folding adds nothing (166 issues); a named
class negated before it is folded (59); only the first letter of a name normalised (14); `Cn` forgetting a category (2); the orbit search
skipping an entry (1,088); `Lc` without titlecase (5).

### Mistakes

- **Stale facts of my own** (above): the `C` difference between Go and XSD, and the idea that Go's property names are exact.
- **Scripted edits again**: one doc edit script stopped on a wrong-escape anchor after half its edits had landed (the Python source had
  doubled backslashes). Raw strings fix it; the lesson is the same as before: verify each edit, not the script's last line.
- **A test I wrote asserted a loose name was invalid**: `L u` is `Lu` in Go (spaces are dropped anywhere). Go decides; the test moved.
