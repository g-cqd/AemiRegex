# Diary — 2026-10-29 (01)

## The engine depends on Aemi (ADR-0013)

The general parts moved into Aemi (aemi ADR 0018) and the engine now depends on it. The renames were mechanical; the property readers were
rewritten over `UnicodeData`, keeping only the dialects' name rules. The suite passed at once (170 tests, the 7 table tests now in Aemi).
The speed table did not: one search per file was 1.3 to 3.4x slower, a constant 0.45 µs a search. Profiles found generic metadata lookups
in the unspecialized pool, then a run-time exclusivity check on its box, then a C call per candidate where the old inline compare loop was
cheaper; each was fixed in Aemi, and every row is now at parity or faster with identical counts.
