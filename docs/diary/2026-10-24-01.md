## Faults and mutations

Baseline proved green first (59 tests). Mutations, each restored from a copy and run until red:

- Phase 1: greedy and lazy swapped; capture restore dropped.
- Assertion machinery: end-of-line ignoring newline; reverse program not mirrored; no match at end of text; start context ignoring the previous byte.
- Empty-match retry removed; pair scan skipping a lane; pair scan overreading by one byte.
- C kernel: 64-byte loop and 16-byte loop overreading by one; wrong lane arithmetic; third block skipped; batch group writing past its capacity;
  window boundary skipping one position.
- DFA loops: forward loop reading `haystack[count]`; reverse loop reading below the floor.

**Not caught the first time:** the pair-scan overread (a poisoned tail made it visible), the reverse-loop overread (invisible in any
output; caught by debug builds and ASan), the candidate-buffer overrun (a dense-candidate test made it visible). The C overreads abort
through the Swift wrapper's fail-closed check, which counts as caught.

## Mistakes

- **The literal matcher was dead code.** The edit anchored on a one-line signature that `swift format` had rewrapped; the script reported
  success, the tests passed because the DFA gives the same answers. Found when a benchmark did not move. `searchCounts` now says which
  engine answered, and a test asserts it.
- **A probe I trusted was unfair** (Teddy, above), and led to a wrong recommendation in the first research note, which carries a dated
  correction.
- **`git checkout <file>` discarded uncommitted edits** to `Prefilter.swift` during mutation testing. Rebuilt from the file's shape and a
  checkpoint commit made. Mutations now restore from copies (AGENTS.md).
- **Two tests of mine were wrong, not the engine:** alternation order (`word5` correctly beats `word57`, twice) and `a{2,3}`, which is a
  literal set (`aaa|aa`). Corrected, and the corrections are in the commit messages.
- **Recursion was audited by name**; the report mixed real recursion (the two generators) with name collisions. Each cycle was read.
