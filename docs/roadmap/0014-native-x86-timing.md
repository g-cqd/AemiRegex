# 0014 — Native x86_64 timing

The C kernel's bar (ADR-0004) is met on arm64; x86_64 is verified for correctness under Rosetta and native Linux CI.
Benchmarking native x86_64 timing requires an Intel or AMD bare-metal runner, which is not currently available in this environment.
